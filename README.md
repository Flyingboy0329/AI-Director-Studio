# AI 導演：影音剪輯決策輔助系統

## 核心定位

AI 導演是一套影音剪輯決策輔助系統。

AI 負責：
- 分析影片
- 理解畫面
- 理解語音
- 整理素材
- 提出剪輯建議
- 解釋建議理由

人類負責：
- 判斷 AI 建議是否合理
- 決定是否採用
- 實際進行影片剪輯

## 核心原則

AI 建議，人類決策。

## MVP

影片
→ 畫面分析
→ 語音分析
→ 素材資訊整合
→ AI 導演建議
→ 結構化報告

## MVP 不包含

- 自動剪輯
- 自動生成完整影片
- 自動操作 DaVinci Resolve
- 自動配樂
- 自動調色
- 從零訓練大型模型

## 主要問題

面對大量非結構化影音素材，
AI 是否能協助剪輯者降低素材初步篩選的時間與認知負擔？
